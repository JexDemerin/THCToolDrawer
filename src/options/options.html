Tool Drawer settings

Settings for this browser. The tools themselves live in the spreadsheet — a super admin edits them there, or from inside the panel.

Spreadsheet connection

The Apps Script web app link, ending in /exec. Everyone on the team points at the same one; when a super admin changes a tool, every drawer picks it up on its own. 


      


      

        
What is stored here

        

          The tool list, so the panel opens instantly and still works if the network is down.
          Nothing else. The super-admin password is checked by the spreadsheet and is never
          written to this browser's disk — it is held in memory for 30 minutes after an unlock
          and cleared when Chrome closes.
        

        

          Keyboard shortcut: Alt + Shift + T opens the panel.
          Change it at chrome://extensions/shortcuts.
